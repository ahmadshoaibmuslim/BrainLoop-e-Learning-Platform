## ❓ TOP 15 EVALUATOR QUESTIONS

**MUST KNOW ANSWERS for these:**

1. **"Why did you build this?"**
   Answer: E-learning platforms are fragmented. Students use Udemy for courses, 
   Wyzant for mentoring, and generic chatbots for support. BrainLoop unifies all three.

2. **"What makes this different from Udemy?"**
   Answer: We added: (1) 1:1 mentoring with video, (2) Intelligent AI support with 
   intent routing, (3) ML recommendations, (4) Multi-vendor architecture

3. **"How does the AI agent work?"**
   Answer: It classifies customer intent (order_status, refund_request, course_info, 
   general) and routes appropriately. Specific intents use handlers, general goes to LLM.

4. **"Why Django and not Node.js?"**
   Answer: Django provides ORM, admin panel, security. Node.js is good too, but Django 
   was our team strength and perfect for structured data.

5. **"How do you prevent fraud?"**
   Answer: JWT authentication, enrollment verification for reviews, CORS security, 
   SSL in production, PCI compliance via Stripe.

6. **"Can it scale to 1M users?"**
   Answer: Yes. Currently single instance. To scale: PostgreSQL replicas, Redis cache, 
   Nginx load balancing, Celery workers, CDN for frontend.

7. **"What about payment security?"**
   Answer: We use Stripe & PayPal SDKs (PCI compliant). Never store CC details. 
   Webhook verification for orders.

8. **"How did you implement recommendations?"**
   Answer: Hybrid approach: 40% collaborative filtering + 30% content-based + 20% 
   popularity + 10% user preferences. Scikit-learn for calculations.

9. **"What if OpenAI API goes down?"**
   Answer: Graceful fallback. We support 4 providers: OpenAI → Groq → Gemini → Ollama. 
   If all fail, return friendly error message.

10. **"How do you handle concurrent requests?"**
    Answer: Django handles concurrency via threading. Database has row-level locking. 
    For high load, we'd use async (Celery + Redis).

11. **"What's your biggest technical challenge?"**
    Answer: Integrating 4 different AI APIs with different response formats. Solved by 
    creating abstraction layer in ai_service.py.

12. **"Why separate the AI agent into different Django app?"**
    Answer: Microservices principle. Independent scaling, different business logic, 
    can deploy separately, easier to integrate with other platforms.

13. **"How do you prevent students from leaving fake reviews?"**
    Answer: Enrollment verification. Code checks if student enrolled before allowing 
    review. Non-students see: "Enroll to review this course"

14. **"What's the most innovative feature?"**
    Answer: Intent-based AI routing. Instead of generic chatbot, we intelligently 
    classify and route. Order query → order handler (fast), general → LLM (conversational).

15. **"How long did this take?"**
    Answer: 165+ development hours. Started with Django tutorial, built architecture, 
    implemented 3 main components, integrated 8+ external APIs, tested everything.
