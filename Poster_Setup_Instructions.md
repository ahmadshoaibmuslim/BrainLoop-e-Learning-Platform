# BrainLoop FYP Poster - Setup Instructions

## Converting Markdown to DOCX

1. **Open the Markdown file**: `BrainLoop_FYP_Poster_Content.md`
2. **Use an online converter**:
   - Go to https://www.markdowntopdf.com/ or https://cloudconvert.com/md-to-docx
   - Upload the `.md` file
   - Download as `.docx`
3. **Or use VS Code extensions**:
   - Install "Markdown Preview Enhanced" extension
   - Open the `.md` file
   - Use "Export to DOCX" feature

## Using the Architecture Diagram in Draw.io

1. **Open Draw.io**: Go to https://app.diagrams.net/
2. **Import the file**:
   - Click "Open Existing Diagram"
   - Upload `BrainLoop_Architecture_Diagram.drawio`
3. **Customize if needed**:
   - Modify colors, layout, or add more details
   - Export as PNG/JPG for the poster
4. **Alternative**: Copy the Mermaid code from the markdown file and paste it into Draw.io's Mermaid import feature

## Poster Layout Recommendations (3ft x 4ft)

### Top Section (1ft height)
- Project Title
- Group Members & Registration Numbers
- Supervisor & Department/University

### Middle Section (2ft height)
- Problem Statement & Objectives
- Architecture Diagram (center, large)
- Main Features (bullet points)

### Bottom Section (1ft height)
- Tools & Technologies (table)
- Screenshots (small thumbnails)
- Results & Conclusion
- QR Code (bottom right)

## Final Tips
- Use high-contrast colors
- Keep text large and readable from 6-10 feet away
- Include visual elements (icons, charts)
- Test print quality before final printing
- Have backup digital version ready
